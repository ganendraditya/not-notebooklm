# Release Notes Draft: v1.4.0 (Pre-Release / In Progress)

## v1.4.0: Automated RAG Ops & Multi-Framework Scientific Benchmarking Testbed

### 🚀 Major Paradigm Shift: From Internal Heuristics to Renowned Multi-Framework Consensus

Prior to v1.4.0, response grounding, citation accuracy, and hallucination checks relied on internal, home-made custom LLM prompts (`rubric_grader_service.py`) evaluated mostly via qualitative spot-checks or unit test mocks. While helpful for basic sanity, custom rubrics carry inherent evaluator bias and lack external academic comparability.

Starting with **v1.4.0**, Not-NotebookLM introduces a rigorous, automated **RAG Ops Evaluation & Multi-Framework Benchmarking Harness**. System outputs are now evaluated against standardized, peer-reviewed evaluation frameworks and global scientific research benchmarks.

---

### 🛠️ What's New in v1.4.0

#### 1. Integration of 5 Industry-Standard Evaluation Frameworks
Instead of trusting a single evaluator, Not-NotebookLM measures performance across five renowned open-source evaluation engines running side-by-side:
- **RAGAS** *(Exploding Gradients - EACL 2024)*: Multi-statement atomic claim decomposition & NLI verification coupled with vector embedding similarity.
- **DeepEval** *(Confident AI)*: G-Eval probabilistic scoring for faithfulness, answer relevancy, and hallucination detection.
- **TruLens** *(TruEra)*: RAG Triad Groundedness with Chain-of-Thought (CoT) reasoning and query-answer relevance tracking.
- **Promptfoo**: Model-graded continuous assertion suite for regression prevention.
- **LlamaIndex Evaluation Core**: Strict contextual entailment verification and ground-truth semantic correctness.

#### 2. Adoption of 5 Renowned Scientific Datasets
To evaluate performance on real-world academic research papers (not toy datasets), the benchmark harness integrates five global datasets:
- **AllenAI QASPER** *(ACL 2021)*: 5,049 questions written by NLP researchers across 1,585 full-text arXiv papers with human-annotated evidence spans.
- **Princeton ALCE** *(EMNLP 2023)*: Automatic LLM citation evaluation benchmarks across ASQA, ELI5, and QAMPARI.
- **AllenAI SciFact** *(EMNLP 2020)*: Scientific claim verification and literature fact-checking.
- **Google Research Attributed-QA**: Verbatim attribution tracking and citation traceability.
- **Meta AI CRAG** *(KDD Cup 2024)*: Comprehensive RAG robustness benchmark testing noise tolerance and unanswerable abstention.

#### 3. Rigorous Evaluation Methodology: Scale Separation Rule
To ensure scientific validity without artificial score dilution or inflation:
- **Separation of Binary Gatekeepers from Continuous Metrics**: Binary 0/1 gatekeepers (such as LlamaIndex `FaithfulnessEvaluator`) are explicitly separated from continuous 0.000–1.000 consensus averages (DeepEval, TruLens, Promptfoo, Ragas) to prevent scale mismatch distortion.
- **Interactive Citation Fidelity (PDF Verbatim Match)**: An exact, zero-token deterministic Python validator that verifies every quoted sentence in `<!-- CITATION_MAP -->` exists verbatim in the physical source PDF.
- **Two-Tier Scorecard**: Executive Summary highlighting the 3 Core Pillars (Groundedness, Relevancy, Correctness) + Full Framework Deep-Dive Ledger.
